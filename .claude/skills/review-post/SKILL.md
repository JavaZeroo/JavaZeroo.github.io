参数：文章路径。先读 skill `post-style` 与 `post-figures`，然后逐项过清单，对每个小节和每张图各查一遍，不抽查。

## 清单

**结构**
- 每个小节开头有动机（上一节的哪个问题引到这里）；结论先行的节标出来。
- 公式是从目标函数/动机推出来的，不是列出来的。
- 超过五步的推导：正文给结论、推导在 `:::details` 里且不跳步。
- 用到上一篇的公式时先回顾并配图。
- 总览类文章：一个机制一个 h2 一张图，各节问题骨架一致。
- 标题写清讲什么，没有纯意象式标题。

**内容**
- 每个数字有出处（论文表号、config 字段），论文没给的量没有被编成常数。
- 通用知识没有混进模型连载；模型连载有链接指向 llm 专栏对应篇。
- 自己补的推理标了「解读」；只在代码里的细节标了来源。
- 站内链接的日期与目标文章 `pubDate` 一致。

**图**
- 图里的公式走 SvgTex/FlowDiagram，没有伪 LaTeX 文本、mermaid、foreignObject。
- 每张图有 label 与 caption；caption 说这张图回答什么。
- 交互 demo 有 `<style is:global>`。
- 组件已提交（`git status` 查 `src/components/`）。

**构建**
- Node 24 下 `npm run build` 通过；截图浅色与深色各一份。

## 输出

先给问题列表（按小节，每条一句话说缺什么），再直接修。完成标准：清单每项对全文每节都核过，修完重新构建通过。
