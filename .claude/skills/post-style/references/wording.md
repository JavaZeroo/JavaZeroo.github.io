# 用词：改写对照

润色或审已有稿子时读。翻译腔的替换建议在 `scripts/wording_scan.py` 里，跑脚本时会直接给出，这里不重复。

## 自造术语

把这个词单独拿去搜，搜不到同一个意思的就是自造的。

| 原文 | 改后 |
|---|---|
| 线性注意力直接用裸点积 | 直接用点积当权重，不取指数，也不归一化 |
| 放松成线性规划 | 松弛成线性规划（LP 松弛） |
| 深度可分的因果卷积 | depthwise 因果卷积（每个通道单独做卷积） |
| 两个槽位轮转 | 双缓冲（double buffering） |

## 单字概念名

整篇文章和图里的标签一起换。引号里只是一个普通的字（「减」「头」）时不用改。

| 原文 | 改后 |
|---|---|
| 加 / 擦 / 忘 | 写入 / 擦除 / 衰减 |
| 读 / 写 / 混 三个算子 | 读算子 / 写算子 / 混合矩阵 |
| **账**：每 token 每层 16 KiB | **开销**：每 token 每层 16 KiB |

## 对仗和口号

| 原文 | 改后 |
|---|---|
| 公式 (1) 的图解：忘对付年龄，擦对付碰撞 | 公式 (1) 的图解：衰减和擦除分别删掉什么 |
| 结构决定系统 | 三个新模块带来的系统改动 |
| 这两件事一个压峰值、一个填空隙 | 动态上下文并行把单个样本的编码时间压下来，气泡调度把这些计算放进空闲时间 |

## 多层比喻

贯穿全文的那一个比喻可以留，套在它外面的去掉。

| 原文 | 改后 |
|---|---|
| 付的货币是 PCIe 带宽 | 代价是 PCIe 带宽 |
| 能拧的旋钮就这么几个 | 能调的量就这么几个 |
| 缓存复用的第一个敌人是负载均衡器 | 第一个妨碍缓存复用的是负载均衡器 |

## 长句

从论文逐句翻过来的段落最容易出这个问题。

> 小 batch 时 group GEMM 退化成对权重矩阵的访存受限流式读取，以 tile 为中心的常规内核为计算密集设计、预处理开销大，不适合。

改后：

> batch 小的时候，group GEMM 基本就是在从显存里一遍遍读权重，算得很少。常规内核是为计算量大的场景设计的，启动前的准备工作又重，放在这里不划算。

几条规则用分号连成一句时，拆成列表，每条写「会出什么错，所以怎么做」。

## 规范的说法进了正文

规范里的要求是给作者看的。正文里出现「每条接一个后果」「用『不是什么』的方式」「两个事实。」这类句子，整句删掉，只留内容。

## 不用改的

- 数值义的「值」：特征值、最小值。
- 已经是标准术语的词：非扩张、共轭算子、次线性、伪值（pseudo-value）。
