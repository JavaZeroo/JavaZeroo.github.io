## 阅读主线

从 MLA 的已有计算路径出发，逐步解释每个新增模块解决什么问题，再解释它究竟从什么标签学习。主线保持图解，复杂误差界、ReLU 函数图与性能估算折叠。

1. MLA 压缩单条 KV，稠密主注意力仍处理全部合法位置。DSA 沿用主 MLA 的表示、主打分与输出路径，改变主计算的候选集合。
2. 六帧结构演进：稠密 MLA → 小索引 key/缓存 → 当前 query 的索引向量和权重 → 多头打分 → top-k 下标 → 将集合接入主 MLA。中间帧是结构拆解，不是执行训练步骤。
3. 三条索引投影：q 复用主 MLA 的 query latent；w 来自当前 hidden；每个候选的 key 来自它自己的 hidden。64 个索引头共享一个 128 维 key；主 MLA 的 128 头是另一组头。
4. 教师来自同层当前 query 的主注意力概率，按头平均；可见位置分布与词表分布分清楚。学习函数会随 query、层、输入变化。
5. KL(p || softmax(I)) 与梯度 r−p。解释负梯度为何抬高低估位置、实际更新投影参数而非固定位置表、为何主 LM loss 不能直接通过 top-k 下标训练 indexer。
6. 稠密冻结热身与稀疏继续训练。集合内教师的支持集、归一化和梯度边界必须保留；主模型参数在稀疏阶段仍更新。
